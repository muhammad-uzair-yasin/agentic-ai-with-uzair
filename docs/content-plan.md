# Agentic Ai with Uzair — content plan (daily AI tools)

## What it is
**One AI tool per day** — a new launch, a free tool, a free tier, or a trending open-source repo — shown in a minute: what it does, a demo, what's free, who it's for.

## Why (Uzair's decision, Oct 31 2026)
The network split into 4 single-purpose channels. Builders and creators want "what can I use today?" — a tools channel answers that daily and pairs naturally with the course (Learn AI) and the news (Ai News). The channel previously carried a bright/white re-cut of the first lesson video; from Nov 1 it's tools only.

## Script shape (~1 min)
1. Hook = the payoff: "This free tool turns any PDF into a podcast." (state the tool's superpower first)
2. What it is (name, who made it) in one line.
3. Demo, acted out: the stick figure uses a realistic UI (cursor clicks, typing, result appearing) — use the 204-element library's WEB UI / MOBILE UI / TECH CODE pieces.
4. Free vs paid — exact limits and price (verified on the official pricing page).
5. Who it's for / one tip.
6. "Subscribe for a new AI tool every day."

## Where tools come from
Daily AI News Digest sections 2 (new tools), 3 (free tools & free tiers), 4 (deals), 7 (creator tools) + trending GitHub repos. Don't duplicate the Ai News episode's tool picks on the same day — go deeper on one.

## Visual direction
Bright, clean "product demo" worlds by default (the channel's first video used white backgrounds, pill captions, cursor + toggle + notification elements, "AGENTIC AI WITH UZAIR" chip) — but the style still adapts to each tool's look.
